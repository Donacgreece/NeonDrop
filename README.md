# NEON DROP

**One thumb. Zero excuses.**

A fast, mobile-first arcade game. Drag the ball left and right, thread the
glowing gates, protect your three lives, and chase a new high score.

## Live website

https://donacgreece.github.io/NeonDrop/

## Highlights

- Smooth one-finger drag controls
- Three-life runs with practice gates
- Progressive speed and narrowing gaps
- Original arcade music and responsive sound effects
- On-device Top 10 leaderboard
- Full-screen mobile experience
- Installable Progressive Web App
- Search and AI discovery metadata

## Privacy

NEON DROP requires no account and collects no personal data. Scores and player
names remain in the browser on the player's device.

## Source

The production-ready static website is in `web/` and is deployed automatically
to GitHub Pages from `main`.
